## 🔧 Интеграция

### Добавить в renderer
```php
public function navbar_modern_data() {
    global $USER, $CFG;
    return [
        'logo' => theme_academi_get_logo_url('header'),
        'sitename' => $this->page->heading,
        'userloggedin' => isloggedin() && !isguestuser(),
        'navitems' => [...],
        'usermenu' => [...],
    ];
}

public function render_modern_navbar() {
    return $this->render_from_template(
        'theme_academi/navbar-modern', 
        $this->navbar_modern_data()
    );
}
```

### Использовать в layout
```php
// В layout/frontpage.php
echo $OUTPUT->render_modern_navbar();
```

## 🐛 Troubleshooting

### Navbar не отображается
```
1. Проверить файлы (ls)
2. Очистить кэш
3. Проверить консоль (F12)
```

### Стили не применяются
```
1. Проверить theme.scss
2. Очистить кэш Moodle
3. Очистить кэш браузера (Ctrl+Shift+R)
```

### JavaScript не работает
```
1. Проверить консоль (F12)
2. Проверить jQuery загружен
3. Добавить js_call_amd в layout
```
