# Product Overview - Academi Moodle Theme

## Project Purpose
Academi is a professional, responsive Moodle theme designed to make online learning portals stand out with modern design and enhanced user experience. It provides a comprehensive visual framework for Moodle 5.0 installations with extensive customization capabilities.

## Value Proposition
- **Professional Appearance**: Enterprise-grade design that elevates the visual appeal of Moodle installations
- **Responsive Design**: Fully responsive layout that works seamlessly across all devices and screen sizes
- **Extensive Customization**: Rich configuration options for branding, layout, and content presentation
- **Modern UI/UX**: Contemporary interface built on Bootstrap/Boost foundation with custom enhancements
- **Multi-language Support**: Built-in internationalization with support for English, Arabic, and Russian

## Key Features and Capabilities

### Visual Customization
- **Custom Branding**: Logo, favicon, and color scheme customization
- **Homepage Slider**: Dynamic slideshow functionality for featured content
- **Marketing Spots**: Configurable promotional areas for highlighting key information
- **Promoted Courses**: Showcase featured courses on the frontpage
- **Jumbotron Section**: Hero section for important announcements
- **Custom Typography**: Multiple font families (Alegreya Sans, Arvo) with web font support

### Layout Options
- **Multiple Page Layouts**: Frontpage, course pages, login, maintenance, embedded, and more
- **Drawer-based Navigation**: Modern sidebar navigation system
- **Block Regions**: Flexible block positioning with side-pre region support
- **Responsive Grid**: Bootstrap-based responsive grid system

### Technical Features
- **SCSS-based Styling**: Modular SCSS architecture with preset themes (default, eguru, enlightlite, klass, plain)
- **AMD JavaScript Modules**: Modern JavaScript with RequireJS for sliders and interactive components
- **Mustache Templates**: Clean template system for maintainable markup
- **Icon System**: FontAwesome integration for consistent iconography
- **Course Index Support**: Enhanced course navigation experience

### Customization Areas
- **General Settings**: Basic theme configuration and branding
- **Home Slider**: Carousel/slideshow configuration
- **Site Features**: Feature highlights and capabilities showcase
- **Footer**: Multi-column footer with social links and custom content
- **Marketing Spots**: Promotional content areas
- **Promoted Courses**: Featured course selection and display

## Target Users

### Primary Users
- **Educational Institutions**: Schools, colleges, universities deploying Moodle LMS
- **Corporate Training**: Organizations using Moodle for employee training and development
- **Online Course Providers**: E-learning platforms and course marketplaces
- **Moodle Administrators**: Site admins seeking professional theme with extensive customization

### Use Cases
1. **Institutional Branding**: Apply institutional identity to Moodle installation
2. **Marketing-focused Frontpage**: Create engaging landing pages to promote courses
3. **Multi-tenant Deployments**: Support multiple visual presets for different audiences
4. **Responsive Learning**: Provide consistent experience across desktop, tablet, and mobile
5. **Localized Installations**: Deploy in multiple languages with proper RTL support
