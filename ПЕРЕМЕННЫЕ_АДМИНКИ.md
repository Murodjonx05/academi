# 🎨 КАК ИСПОЛЬЗОВАТЬ ПЕРЕМЕННЫЕ ИЗ АДМИНКИ

## 📋 Доступные переменные

Все переменные, которые вы настраиваете в админке, автоматически доступны через CSS Custom Properties:

### Основные цвета
```css
--academi-primary          /* Основной цвет (Primary Color) */
--academi-secondary        /* Вторичный цвет (Secondary Color) */
--academi-accent           /* Акцентный цвет */
--academi-text-primary     /* Цвет текста */
--academi-text-inverse     /* Цвет текста на темном фоне */
--academi-nav-bg           /* Фон navbar */
--academi-nav-text         /* Цвет текста navbar */
--academi-surface-muted    /* Приглушенный фон */
```

## 🔧 Примеры использования

### В SCSS файлах
```scss
// Использование переменных с fallback
.my-component {
    background: var(--academi-primary, #2563eb);
    color: var(--academi-text-inverse, #ffffff);
    border-radius: $radius-lg; // 16px - дружелюбный
}

// Кнопка с переменными админки
.btn-custom {
    background: var(--academi-primary);
    color: var(--academi-text-inverse);
    border-radius: $radius-lg; // Дружелюбный rounded
    padding: 12px 24px;
    
    &:hover {
        filter: brightness(1.1);
    }
}
```

### В CSS файлах
```css
/* Карточка курса */
.course-card {
    background: white;
    border: 2px solid var(--academi-primary);
    border-radius: 16px; /* Дружелюбный rounded */
    padding: 24px;
}

/* Заголовок с цветом из админки */
.page-title {
    color: var(--academi-primary);
    font-size: 28.83px;
}
```

### В Mustache шаблонах
```html
<!-- Кнопка с классами -->
<button class="btn btn-primary">
    Нажми меня
</button>

<!-- Карточка -->
<div class="modern-card">
    <h3>Заголовок</h3>
    <p>Контент</p>
</div>
```

## 🔄 Как добавить новую переменную

### Шаг 1: Добавить в settings
В `settings/general.php`:
```php
$setting = new admin_setting_configcolourpicker(
    'theme_academi/mycolor',
    get_string('mycolor', 'theme_academi'),
    get_string('mycolor_desc', 'theme_academi'),
    '#2563eb'
);
$page->add($setting);
```

### Шаг 2: Добавить в lib.php
В функцию `theme_academi_inject_css_variables()`:
```php
$mycolor = theme_academi_get_setting('mycolor') ?: '#2563eb';
$css_variables .= "  --academi-mycolor: {$mycolor};\n";
```

### Шаг 3: Использовать в SCSS
```scss
.my-element {
    background: var(--academi-mycolor, #2563eb);
}
```

## 📊 Текущие переменные в админке

### General Settings
- `primarycolor` → `--academi-primary`
- `secondarycolor` → `--academi-secondary`
- `textcolor` → `--academi-text-primary`
- `textcolorinverse` → `--academi-text-inverse`

### Navigation
- `navbg` → `--academi-nav-bg`
- `navtext` → `--academi-nav-text`

### Advanced
- `surface_muted` → `--academi-surface-muted`

## 🎨 Дружелюбные радиусы (Rounded)

Все компоненты используют дружелюбные радиусы:

```scss
$radius-sm: 8px;   // Маленький
$radius-md: 12px;  // Средний (кнопки)
$radius-lg: 16px;  // Большой (карточки)
$radius-xl: 20px;  // Очень большой
```

### Примеры:
```scss
// Кнопка
.btn {
    border-radius: $radius-md; // 12px
}

// Карточка
.card {
    border-radius: $radius-lg; // 16px
}

// Модальное окно
.modal {
    border-radius: $radius-xl; // 20px
}
```

## 🚀 Быстрый тест

1. Откройте админку: `Site administration > Appearance > Themes > Academi`
2. Измените `Primary Color` на красный (#ef4444)
3. Сохраните
4. Очистите кэш: `php admin/cli/purge_caches.php`
5. Обновите страницу - все кнопки `.btn-primary` станут красными!
